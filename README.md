# A股 / 场内ETF 历史表现看板

纯静态网页，零依赖、无后端。输入任意 **A 股（沪深主板 / 科创板 / 创业板 / 北交所）或场内 ETF / LOF** 的代码、名称、拼音首字母，即可查看：

| 模块 | 内容 |
| --- | --- |
| ① 对数走势 | 以区间首日为 1.0x 的净值倍数（对数坐标）、区间总收益、**CAGR 年化收益**、匀速增长参考线 |
| ② 回撤 | 回撤曲线、**最大回撤幅度**、峰→谷历时、修复用时、当前回撤、主要回撤历时标注 |
| ③ 牛熊周期 | ZigZag 峰谷法划分牛（红）熊（绿）阶段，标注每段的结束年月 · 历时 · 涨跌幅（≥12 个月附年化） |
| ④ 多尺度涨跌 | 1周 / 1月 / 3月 / 6月 / 年初至今 / 距前高 / 1年 / 24年9月24日至今 / 3年 / 5年 / 10年 / 20年 / 上市至今 / 15年6月12日至今 / 21年2月18日至今 |
| ⑤ 分红（仅股票） | 股息率(近12月)、近12月每股分红、连续分红年数、分红年数 x/N、平均股息率、派息率、分红贡献（分红再投资年化 − 纯价格年化）、分红明细表；口径与全市场筛选表相同 |
| 附加 | 年度涨跌幅（含每个会计年度的每股分红 / 股息率(年末价)）、分周期（日/周/月/季/年）涨跌统计、牛熊阶段明细表、导出 PNG |

数据来源：东方财富公开日线接口（JSONP 方式实时拉取，默认前复权）与东方财富分红明细接口，**浏览器直接请求，无需任何服务器**。

## 在 MacBook 上使用

1. 在本仓库页面点 **Code → Download ZIP**，或：
   ```bash
   git clone https://github.com/vickingwu/astock-perf.git
   ```
2. 解压后 **双击 `screen.html`**（主页，全市场筛选表，无需联网）；在它的筛选框里输入 6 位代码回车，即打开该标的的个股看板 `index.html`（需联网拉取行情；ETF / LOF 代码亦可）。直接打开不带参数的 `index.html` 会自动跳到 `screen.html`。
3. 看板页内输入 `600749`、`西藏旅游` 或 `xzly` 回车切换标的；也可直接改 URL 里的参数（`index.html#s=…` 深链接照常可用）：

   ```
   index.html#s=1.600749&r=10y&fqt=1&th=0.2
   ```
   - `s`：`市场.代码`（`1`=沪，`0`=深/北），如 `1.510300`、`0.159915`
   - `r`：区间 `all / 20y / 10y / 5y / 3y / 1y`
   - `fqt`：复权 `1`=前复权 `2`=后复权 `0`=不复权
   - `th`：牛熊阈值，如 `0.2` = 20%
   - `b`（可选）：牛熊划分依据 `M`=月收盘 `W`=周收盘 `D`=日收盘，默认按区间长度自动选择

   在线版：筛选表（主页）<https://vickingwu.github.io/astock-perf/>，看板示例 <https://vickingwu.github.io/astock-perf/index.html#s=1.600749>。

> 若浏览器提示无法加载数据，请确认能访问 `push2his.eastmoney.com`（公司网络 / 代理可能拦截）。

## 文件说明

```
screen.html  全市场筛选（主页）；筛选框输入 6 位代码回车 → 个股看板
screen/data/   全市场筛选的数据文件（screen.html 按需加载，须与 screen.html 一同保留）
index.html   个股看板（不带 #s= 参数打开时自动跳到 screen.html）
style.css    样式
app.js       取数、计算（CAGR / 回撤 / ZigZag 牛熊 / 多尺度统计）与 SVG 绘图
dividends.js 分红口径（事件归一化 / 股息率 / 连续分红 / 分红年数 / 平均股息率 / 派息率 / 再投资年化），看板与 tools/screen_all.js 共用
stocks.js    全部 A 股 + 场内 ETF + 场内 LOF 代码表（含拼音首字母），由脚本生成
tools/build_stock_list.js   重新生成 stocks.js 的脚本
```

### 批量分析一组标的

`tools/batch_report.js` 复用 `app.js` 的计算引擎，对脚本顶部 `ASSETS` 列表逐个拉数（股票/ETF 走东方财富日线，场外基金走天天基金复权净值），在当前目录输出 `results.json` 与 `summary.md`（年化、最大回撤、修复用时、牛熊阶段、多尺度涨跌一览）：

```bash
node tools/batch_report.js
```

### 更新股票列表（新股上市后）

```bash
npm install                      # 仅首次，安装 pinyin-pro
node tools/build_stock_list.js   # 重新生成 stocks.js
```

本地列表找不到的新品种，页面会自动退回东方财富联想接口查询；也可以直接输入 6 位代码回车。

## 方法说明

- **CAGR**：`(终值/初值)^(365.25/天数) − 1`，初值为区间首个交易日收盘。
- **回撤**：收盘价相对此前最高收盘的跌幅；最大回撤历时为峰→谷天数，修复用时为谷→重回前高天数。
- **牛熊划分（ZigZag）**：自阶段高点回落超过阈值即确认熊市开始，自阶段低点反弹超过阈值即确认牛市开始；此外，价格跌破本轮牛市的起点（上一个谷）同样判定牛市结束——更低的低点本身就否定了牛市。先在月 / 周收盘序列上识别转折（过滤短期噪音），再在相邻转折之间用日收盘精确定位峰谷；进行中的阶段须自起点起走出过一次 ≥阈值的行情，否则并入上一阶段。首段与末段为截断阶段，幅度可能小于阈值。
- **"牛市阶段"是技术性定义**：模型只有牛 / 熊两态，"牛市阶段" = 自谷底反弹已超过阈值且尚未从阶段高点回落超过阈值，因此多年横盘、反弹后大部分回吐、刚过阈值的小反弹都会归为"牛"。页面在牛熊卡片、阶段标签和明细表中给出"距阶段高点 / 低点"，请结合它与"距区间前高"一起判断。
- **多尺度涨跌**：以最新收盘为基准，对比 N 个自然日/月/年前（取不晚于该日的最近交易日）收盘；"24年9月24日至今"基准为 2024-09-23 收盘。
- 前复权价格出现非正值时（部分高分红老股），自动改用后复权。
- **分红**（仅股票；ETF / LOF 不显示分红卡片）：数据来自东方财富分红明细（`RPT_SHAREBONUS_DET`，与全市场筛选同一数据源；接口只按 6 位代码过滤，页面再按 `SECUCODE` 后缀核对市场——沪市 .SH、深市 / 北交所 .SZ / .BJ——避免手输 hash 打开指数时串入同号深市个股的分红表）与东方财富不复权日线（`fqt=0`），两者与 K 线并行拉取，分红接口不可用时卡片显示「分红数据暂不可用」、其余模块不受影响。事件 = 「实施」且已除息（除息日 ≤ 最新交易日）的记录，每股税前现金 = 每 10 股派现 ÷ 10，送转因子 = 1 + (送 + 转) / 10，会计年度 = 报告期年份（无报告期按除息月归属：1–8 月 → 上一年度）。最近完整会计年度（连续分红 / 分红年数的终点）：9–12 月为最新交易日所在年 − 1，与筛选表相同（筛选表的数据截止日固定在 10 月）；1–8 月是上一年度年报分红的实施季，若上一年度尚无已实施的现金分红则取所在年 − 2，卡片提示「FYxxxx 年报分红尚未实施」——否则每年只派一次年报股息的公司在 1 月到除息日之间会显示为连续分红 0 年（按 2026-10-15 的分红表推算，3 月初约 66% 的连续分红 ≥ 5 年个股会受影响）；若上一年度已实施了中期 / 季度派息但年报派息还没除息（如贵州茅台 2026 年 3 月：FY2025 中期 23.957 元已除息，年报 28.024 元 6 月才除息），仍计为该年度，但连续分红 / 分红年数 / 平均股息率下方与该年芯片提示「FYxxxx 年报分红尚未实施（已含中期）」，该年度的每股分红与股息率暂只含中期。股息率(近12月)（近 365 天内除息的每股现金，按其后送转折算，÷ 最新不复权收盘）/ 连续分红 / 分红年数 x/N / 平均股息率（各年度现金 ÷ 除息月前一月末收盘，÷ 区间年度数）/ 派息率（Σ 现金 ÷ Σ 年报基本 EPS）的定义与 `screen.html` 筛选表 v3.1 完全相同（见 [screen/README.md](screen/README.md)），由同一份 `dividends.js` 计算；连续分红与股息率(近12月)不随区间变化，其余随所选区间（all / 20y / 10y / 5y / 3y / 1y → 会计年度 区间首年 … 最近完整年度）变化。**分红贡献 = 分红再投资年化 − 纯价格年化**：看板用不复权日线、从所选区间首个交易日起、每笔现金在除息后首个交易日按收盘再投资、送转按因子调份额，纯价格年化只计送转。页面顶部的「年化收益 CAGR」按所选复权方式计算，与分红贡献口径不同。年度涨跌幅芯片下方的「每股分红」为该会计年度每股税前现金，「股息率(年末价)」= 该现金 ÷ 该年最后一根不复权收盘。**与筛选表的差异**：① 筛选表用月末价近似再投资（除息后首个月末），年化(分红再投资) / 分红贡献 因此略有差异（数据截止 2026-10-15 时工商银行 601398：看板 9.85% / 4.96 pp，筛选表 9.84% / 4.95 pp）。② 筛选表以后复权序列对账：补齐明细表缺失的特别股息（2026-10-15 一轮 71 只，如贵州茅台 2022 / 2023 年特别分红，补齐后其平均股息率与分红贡献高于看板），并对送转 / 配股与明细表不符的个股（`recon_drift`：上市至今 770 只、近10年 100 只、近5年 52 只）把 年化(分红再投资) / 纯价格年化 / 分红贡献 置空；看板没有后复权对账，这三项对所有个股都显示，但在后复权视图下用同区间后复权年化复刻筛选表的 `hfq_gap` 标记——年化(分红再投资)与同区间后复权年化相差超过 2 个百分点时，分红贡献下方提示差值与「hfq_gap：复权口径差异，或分红表缺送转 / 配股记录」（东财复权对现金是加性处理、相当于分红不再投资，银行等长历史高股息个股的差值天然较大）。前复权 / 不复权视图不做此判定：筛选表以后复权定义该标记，而东财前复权从历史价中扣减其后全部分红，区间起点价被压低、区间年化系统性偏高，与再投资年化不可比（合成 10 年、5% 股息率、无送转个股：对后复权差 +1.0 pp 不标，对前复权差 −2.7 pp 会误标），分红较多的老股前复权还会出现非正价格、页面自动改用后复权。③ 平均股息率里「除息前一月末收盘」的回退锚点：看板用上市首日不复权收盘，筛选表只在上市首日锚点与后复权序列对账一致时才用它，否则上市当月除息的事件不计股息率。

## 全市场筛选（screen.html）

仓库根目录的 `screen.html` 是一张可排序的全市场总表：沪深主板 + 创业板 + 科创板约 4,100 只非 ST、上市满 5 年的个股，用本页同一套 `app.js` 引擎逐只算出 30% / 40% / 50% 三个牛熊阈值下的年化、最大回撤、熊市均跌、牛市新高率等指标与综合排名，支持上市至今 / 近10年 / 近5年三个区间与板块筛选，每行可点回本看板核对。v3.1 起另有「分红」列组（股息率(近12月)、分红年数 x/N、连续分红年数、平均股息率、派息率、分红贡献 = 分红再投资年化 − 纯价格年化、红利榜名次，数据来自东方财富分红明细与腾讯不复权行情），以及「只看红利榜 Top 50」「连续分红 ≥ n 年」「显示分红列」三个筛选 / 显示开关；现有指标与综合排名不受影响。
